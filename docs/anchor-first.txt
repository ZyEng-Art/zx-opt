Anchor-first ZX search (2026-10-18)

Opt in with --selection anchor. The default global mode retains the baseline.
Example:
  python -m zxopt.general_search runs/anchor --general-zx --selection anchor \
    --policy online --seconds 600 --rollout 32 --total-candidate-cap 32

The selector encodes topology-only anchors before querying rule applicability.
It samples one raw node, raw edge, closed wire, global scalar location, or
scoring-view node/H edge. Raw and normalized scoring IDs remain separate.
Native predicates receive restricted starting vertices/edges with their full
host neighborhoods. General templates pin a distinguished pattern vertex and
extend through adjacent host vertices. Simple S/I/H proposals use incidence
queries. At most eight local candidates are previewed by default.
Some axioms also contain disconnected scalar components. Their main component
is rooted, while the disconnected parts still query host labels globally under
the same work budget. A fixed-radius match would incorrectly omit those axiom
instances; selected-anchor matching does not make every rule strictly local.

This borrows Quarl's selected-location matching order, not its entire learning
algorithm. In particular Quarl samples nodes from temperature-scaled critic
values; this mode learns the anchor actor with PPO. The PPO ratio uses
log p(anchor|graph) + log p(instance|graph,anchor,local menu). Both menu and
selected anchor are retained in each rollout, including complete checkpoints.
It never rematches during PPO. The entropy bonus is an explicitly sampled
conditional regularizer rather than exact full hierarchical entropy.

If no resource-feasible local instance exists, the attempted anchor is an
explicit zero-reward unchanged-state transition, with terminal horizon handling
and its anchor probability logged. No retry conditions the distribution on
unknown rewritability. Noops do not enter the archive, change latent depth,
reset gate patience or count as accepted rewrites. They must be reported
separately from productive transitions in speed/learning comparisons.

Finite local menus, phase splits and work limits still sacrifice exhaustive
search. This changes the proposal distribution. Faster matching does not prove
better final gate counts; compare equal wall time and frozen controls per
target, with independent model initialization for every seed/circuit.

The existing node22/node23 long jobs keep immutable source f5874e497ce1.
This branch and its runs are isolated; those jobs are not restarted or replaced.

Tests check rooted/global embedding coverage on a finite host, reachable
instances of all12 schemata in both directions, wire/scalar cases, arbitrary
phase inference, native query/preview replay, joint density, both actor stages,
and finite PPO updates. Full run audits replay accepted proofs and verify saved
NAM circuits; large circuits use the existing sufficient ZX certificate and
inconclusive cases are excluded, not called proven incorrect.

2026-10-18 follow-up experiments:
--anchor-prior nodes is an optional topology-only logit prior. Initial category
mass is35% raw Z/X nodes,10% raw H nodes,45% scoring-view Z nodes,4.5% raw edges,
4.5% scoring-view H edges,1% global/closed-wire scalar locations. Absent groups
renormalize automatically. All anchors retain positive support; the prior is
included in both sampling and PPO probabilities. Default uniform is unchanged.
This is a search bias, not a learned applicability oracle or a completeness
guarantee. Frozen controls are required to separate this bias from PPO benefit.

--learning-rate defaults to0.0003; optional0.001 is a separate experiment.
Campaign modes anchor8_nodes, anchor8_lr1e3, anchor8_nodes_lr1e3 isolate these
changes against anchor8 and global32. All are independent on-target runs.

The anchor PPO metrics now report normalized anchor and local entropies
separately. Conditional normalized local entropy divides only by the fraction
of non-forced local actions. The initial implementation incorrectly applied
that division to combined anchor/local entropy, so historical values above1
of conditional_normalized_entropy are not valid convergence evidence. This is
read-only instrumentation; the PPO gradient/objective is unchanged.

--anchor-resource-mask is another opt-in experiment. It excludes raw wire and
closed-wire anchors when their I-backward insertion (+1 node,+1 wire) cannot
fit, and global E-backward insertion anchors (+2 nodes,+1 wire) when they cannot
fit. Raw HH pairs can offset growth, so unnormalized foreign raw contexts are
left unfiltered. Normal search states already cancel HH pairs after each step.
Scoring-view H-edge insertion is measured against the normalized view's raw
representation, not against the current raw state's size; its growth is+4 raw
nodes/+4 wires. Unsupported scalar-size estimation leaves the anchor available
for the existing exact preview. Node anchors are never removed by this mask.
No rule matching, candidate rewriting or cost lookahead occurs before sampling.
The mask and its prior remain part of the recorded PPO categorical support.
Gate rewards, archive admission and gate-plateau stopping remain unchanged.

The actor's deterministic scores are now reused within a single search step:
once for the anchor sample and once for the local instance sample, then the
same tensors provide their recorded log probabilities. There is no cross-state
or cross-update cache. The critic is still evaluated for each sampled step,
and PPO recomputes the actor for every optimizer minibatch. Read-only PPO
diagnostics also avoid duplicating the same actor forwards. Fixed-step trace
and parameter comparisons are required before calling this computation-only.

2026-10-18 restart-pool experiment (opt-in)
  --archive-qasm-cap 2 limits scored restart representatives per SHA256 of an
  already verified extracted QASM. Within a group, retain fewer raw nodes,
  then fewer wires, then the stable raw digest; always retain the original
  root. At the global capacity, gate/CX quality remains primary and raw size
  breaks ties. Unknown-cost states still use the unchanged latent archive.
  No extra extraction or cost lookahead is performed. Every legal child can
  remain active even when not admitted as a future restart. This is a search
  heuristic: raw diagrams producing the same extracted circuit can offer
  different future rewrites, so this pruning has no completeness guarantee.
  The default0 preserves the prior archive behavior. Campaign arms
  anchor8_qasm2 and anchor8_resource_qasm2 isolate this change against their
  corresponding anchor8 baselines, with paired frozen/online policies.
  Full-state checkpoints retain group signatures/counters, and replay audits
  reconstruct every admission, eviction and restart from verified QASM hashes.

  Diagnostic evidence: prior-path-diagnostics.json covers47 closed reports in
  the original prior/LR study, which failed overall because3 other trials
  raised vendor-wrapped deadline alarms. Of438618 recorded transitions,
  189847 were more than6 gates above the incumbent.52 of89 strict improvement
  events had a current restart-trajectory prefix crossing that threshold.
  These are observational counts (some frozen LR controls duplicate paths),
  not independent samples or a prediction of counterfactual truncated search.
  Prefixes do not include ancestry before their buffer restart. This evidence
  does not justify enabling a global incumbent+6 bound without an ablation.
  The64-state scored pools had median known extracted-QASM counts4.5 frozen
  and2 online (63mapped states), with most raw states close to the node cap.
  Different normalized graph keys remain common; exact view dedup alone would
  not remove most of these completion-equivalent raw variants.

2026-10-18 frozen learned-weight probes
  tools/policy_weight_probes.py consumes a completed, replay-audited training
  campaign. For every specified mode/training seed it freezes both the
  initial and final weights, then searches the original same-circuit input
  with matched fresh search RNG seeds and wall budgets. It transfers no
  incumbent circuit, active state, optimizer or restart pool. All arms use
  --policy frozen, and the auditor checks zero parameter change throughout
  each probe. This isolates retained final-policy behavior from changes in
  online policy and restart-pool history; it does not test other circuits.
  All planned training models are included, rather than selecting the run
  with the smallest final gate count. Controls reused across learning-rate
  variants are correlated and are not independent statistical samples.

  Model packages include input/policy-support checks, exact source model,
  protocol, event, report and training-audit hashes, and tensor digests.
  --resume-model now stores an exact byte snapshot inside every new run and
  records its digest; its protocol explicitly identifies model continuation
  instead of claiming a fresh-model run. Replay auditing checks initial
  weights against the recorded digest and byte/tensor equality with that
  snapshot. Non-finite, other-input and incompatible policy-support models
  are rejected before use. Optimizer continuation remains available only
  with --policy online; these probes never create an optimizer.

  Launch after the training source reaches an audited terminal pass:
    python3 tools/launch_anchor_node.py runs/anchor-probes-launch-20261018 \
      --node 23 --tag anchor_probes --experiment policy-probe \
      --probe-source-tag anchor_long --seconds 900 --workers 12 \
      --cpus 24 --memory-gib 64 --audit-workers 4 \
      --circuits barenco_tof_3 --training-seeds 137 163 197 \
      --seeds 401 431 461 \
      --modes global32 anchor8_resource anchor8_resource_lr1e4
  The training source is mounted read-only in a separate owned container.
  The launch refuses an incomplete or failed source campaign. Archives and
  event/circuit/parameter audits use the same terminal collection workflow.

2026-10-18 optional native CFlow scores
  Build with: python tools/build_native_scores.py runs/native-backend
  --native-flow-module PATH_TO_SO loads that directory's extension only when
  its binary/source hashes match build.json. --verify-native-flow additionally
  compares every scoring batch and match update against pinned PyZX (slow).
  The extension computes exact integer LC, pivot and identity-fusion scores.
  It preserves score types, None values and input order; Python still performs
  all matching, tie handling and rewriting. Adjacency bitsets are rebuilt for
  each call and are never retained across graph rewrites. Unsupported graph
  representations/self-loops and graphs above8192vertices use the existing
  Python fallback. The default remains Python; no shared dependency directory
  or frozen legacy file is modified. The module has no GPU runtime dependency.
  Protocols retain source/binary/build-receipt hashes, and reports retain
  native batch/score/fallback/verification counts separately for both oracles.
  A103-test suite and a384-step online development run checked782035native
  scores and every match update exactly; fixed-step full trace/model and Linux
  builds are required before any throughput or training-quality claim.

2026-10-18 trajectory credit experiments
  --anchor-noop-stop is opt-in and applies only to anchor selection. An empty
  local menu still produces the recorded unchanged-state, zero-reward noop,
  with its joint anchor/action log probability and no archive admission or
  accepted-rewrite increment. With this flag it is terminal; the next action
  follows the existing archive/root restart policy. This adapts the nop_stop
  concept in Quarl's actor to the existing empty-anchor noop. The default
  continues within the current trajectory. It adds no gate reward or penalty.

  The rollout128 arm collects128steps before updating rather than32. GAE,
  four PPO epochs and the32-sample gradient minibatch stay unchanged. It is
  a collection/credit-window experiment, not a128-graph inference batch.
  Four conditions (neither change, stop, rollout128, both), all at learning
  rate1e-4 with resource masking and the same native CPU scoring backend,
  isolate the two effects. Frozen32/128 controls have identical search
  policies and RNG paths and are explicitly correlated. Each target circuit
  is trained independently; this experiment uses only barenco_tof_3.

  --save-improvement-models saves an immutable policy/Adam snapshot at each
  strict total-gate improvement, before updating on that transition. CX ties
  do not create such snapshots. The original input, policy support, step,
  update count and source revision remain in the capsule; best-history.jsonl
  records its path and SHA256. Saving and hashing pay search wall time. This
  retains the policy that generated an improvement even if later PPO updates
  drift. It transfers no circuit or restart state. Uniform policies have no
  model to save. The option defaults off; normal runs retain initial/final
  checkpoints as before. Replay audits bind each snapshot to the actual best
  improvement event, validate finite/compatible weights and check byte hashes.

2026-10-18 optional rooted audit replay
  tools/audit_general.py --native-replay rooted checks each recorded native
  witness through the existing rooted matcher, retaining full host neighborhoods,
  then executes the hash-guarded frozen rewrite prefix. It skips the legacy
  post-rewrite global menus and neural observations, which are not audit outputs.
  Gadget fusion remaps local group indices while preserving the recorded root
  order. Exact saved-child records, HH receipts, fixed-wire operator checks,
  QASM costs, rewards, archive admission, model and snapshot checks remain.
  --crosscheck-native-every 1 also executes the reference path for every native
  transition; larger positive intervals periodically crosscheck. Reference is
  still the default. An alternating-order 200-rewrite component benchmark gave
  5.02x on one local host; loading, normalization and operator checks were outside
  that timer. This is not a training or complete-audit speedup measurement.

2026-10-18 neutral trajectory allocation experiment
  --neutral-stop-steps N is opt-in, default0. Count only accepted scored
  rewrites or unchanged scored-state noops with exactly zero total-gate reward.
  A cost-changing, unscored or rejected step resets the counter, as does an
  archive restart. On the Nth neutral step record the actual unchanged reward
  and normal archive handling, mark the transition terminal, then use the
  existing restart distribution next step. No reward penalty or legal-rule
  filter is added. CX-only improvements are neutral for this total-gate rule.

  When enabled, context entry8 contains neutral_streak/N in place of the
  redundant latent-depth indicator, keeping the stopping state visible to
  actor and critic. The other depth/cost indicators remain available. Model
  continuations must use the same limit; full checkpoints retain the counter.
  The default context, policy schema and RNG path are unchanged.

  Closed one-hour trajectories motivated an N32 comparison: all observed
  strict gate-improvement trajectory prefixes had peak neutral runs below32
  (maximum23). These are correlated on-target observations with full study
  audits pending, not a guarantee. Useful longer plateaus can be discarded;
  this bounded search heuristic carries no completeness/convergence claim.
  Fresh seeds617/641/673/701 will compare native-CPU resource-masked low-LR
  baseline versus neutral32, frozen/online, each3600s, preserving strict-gate
  policy snapshots. The original26 three-hour-patience jobs remain separate.

  New campaign/probe launchers accept --audit-native-replay rooted and
  --audit-crosscheck-native-every 101. These
  select the optional witness replay and periodic full-path crosschecks; the
  default remains reference. Audit choice never changes search/training.

2026-10-18 exact export computation
  The adapter's greedy drawing-row order is unchanged: minimize the cut-change
  integer, then vertex ID. Precompute degree minus twice the number of already
  processed neighbors, update each affected neighbor by minus2, and use a heap
  with stale-entry checks. Graph construction, IDs, wire types, phases, boundary
  ordering, scalar and chosen drawing rows remain identical. No graph cache is
  retained across calls. Internal Phase imports are resolved once at module
  load instead of millions of times during phase validation; angle arithmetic
  and acceptance predicates are unchanged.

  117tests,300saved raw diagrams with exact full-export JSON and independent
  operator checks, and four512-step frozen/online trajectories (baseline and
  neutral32) passed. Actions, rewards, restart archives and final model tensors
  are bitwise equal to retained controls. An alternating-order export-only
  benchmark measured4.87x locally, excluding shared phase-helper work and all
  verification from its timer. Full training/audit speedups need Linux evidence.
