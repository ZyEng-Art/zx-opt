Anchor-first ZX search (2026-10-18)

Opt in with --selection anchor. The default global mode retains the baseline.
Example:
  python -m zxopt.general_search runs/anchor --general-zx --selection anchor \
    --policy online --seconds 600 --rollout 32 --total-candidate-cap 32

The selector encodes topology-only anchors before querying rule applicability.
It samples one raw node, raw edge, closed wire, global scalar location, or
scoring-view node/H edge. Raw and normalized scoring IDs remain separate.
Native predicates receive restricted starting vertices/edges with their full
host neighborhoods. General templates pin a distinguished pattern vertex and
extend through adjacent host vertices. Simple S/I/H proposals use incidence
queries. At most eight local candidates are previewed by default.
Some axioms also contain disconnected scalar components. Their main component
is rooted, while the disconnected parts still query host labels globally under
the same work budget. A fixed-radius match would incorrectly omit those axiom
instances; selected-anchor matching does not make every rule strictly local.

This borrows Quarl's selected-location matching order, not its entire learning
algorithm. In particular Quarl samples nodes from temperature-scaled critic
values; this mode learns the anchor actor with PPO. The PPO ratio uses
log p(anchor|graph) + log p(instance|graph,anchor,local menu). Both menu and
selected anchor are retained in each rollout, including complete checkpoints.
It never rematches during PPO. The entropy bonus is an explicitly sampled
conditional regularizer rather than exact full hierarchical entropy.

If no resource-feasible local instance exists, the attempted anchor is an
explicit zero-reward unchanged-state transition, with terminal horizon handling
and its anchor probability logged. No retry conditions the distribution on
unknown rewritability. Noops do not enter the archive, change latent depth,
reset gate patience or count as accepted rewrites. They must be reported
separately from productive transitions in speed/learning comparisons.

Finite local menus, phase splits and work limits still sacrifice exhaustive
search. This changes the proposal distribution. Faster matching does not prove
better final gate counts; compare equal wall time and frozen controls per
target, with independent model initialization for every seed/circuit.

The existing node22/node23 long jobs keep immutable source f5874e497ce1.
This branch and its runs are isolated; those jobs are not restarted or replaced.

Tests check rooted/global embedding coverage on a finite host, reachable
instances of all12 schemata in both directions, wire/scalar cases, arbitrary
phase inference, native query/preview replay, joint density, both actor stages,
and finite PPO updates. Full run audits replay accepted proofs and verify saved
NAM circuits; large circuits use the existing sufficient ZX certificate and
inconclusive cases are excluded, not called proven incorrect.

2026-10-18 follow-up experiments:
--anchor-prior nodes is an optional topology-only logit prior. Initial category
mass is35% raw Z/X nodes,10% raw H nodes,45% scoring-view Z nodes,4.5% raw edges,
4.5% scoring-view H edges,1% global/closed-wire scalar locations. Absent groups
renormalize automatically. All anchors retain positive support; the prior is
included in both sampling and PPO probabilities. Default uniform is unchanged.
This is a search bias, not a learned applicability oracle or a completeness
guarantee. Frozen controls are required to separate this bias from PPO benefit.

--learning-rate defaults to0.0003; optional0.001 is a separate experiment.
Campaign modes anchor8_nodes, anchor8_lr1e3, anchor8_nodes_lr1e3 isolate these
changes against anchor8 and global32. All are independent on-target runs.

The anchor PPO metrics now report normalized anchor and local entropies
separately. Conditional normalized local entropy divides only by the fraction
of non-forced local actions. The initial implementation incorrectly applied
that division to combined anchor/local entropy, so historical values above1
of conditional_normalized_entropy are not valid convergence evidence. This is
read-only instrumentation; the PPO gradient/objective is unchanged.

--anchor-resource-mask is another opt-in experiment. It excludes raw wire and
closed-wire anchors when their I-backward insertion (+1 node,+1 wire) cannot
fit, and global E-backward insertion anchors (+2 nodes,+1 wire) when they cannot
fit. Raw HH pairs can offset growth, so unnormalized foreign raw contexts are
left unfiltered. Normal search states already cancel HH pairs after each step.
Scoring-view H-edge insertion is measured against the normalized view's raw
representation, not against the current raw state's size; its growth is+4 raw
nodes/+4 wires. Unsupported scalar-size estimation leaves the anchor available
for the existing exact preview. Node anchors are never removed by this mask.
No rule matching, candidate rewriting or cost lookahead occurs before sampling.
The mask and its prior remain part of the recorded PPO categorical support.
Gate rewards, archive admission and gate-plateau stopping remain unchanged.

The actor's deterministic scores are now reused within a single search step:
once for the anchor sample and once for the local instance sample, then the
same tensors provide their recorded log probabilities. There is no cross-state
or cross-update cache. The critic is still evaluated for each sampled step,
and PPO recomputes the actor for every optimizer minibatch. Read-only PPO
diagnostics also avoid duplicating the same actor forwards. Fixed-step trace
and parameter comparisons are required before calling this computation-only.

2026-10-18 restart-pool experiment (opt-in)
  --archive-qasm-cap 2 limits scored restart representatives per SHA256 of an
  already verified extracted QASM. Within a group, retain fewer raw nodes,
  then fewer wires, then the stable raw digest; always retain the original
  root. At the global capacity, gate/CX quality remains primary and raw size
  breaks ties. Unknown-cost states still use the unchanged latent archive.
  No extra extraction or cost lookahead is performed. Every legal child can
  remain active even when not admitted as a future restart. This is a search
  heuristic: raw diagrams producing the same extracted circuit can offer
  different future rewrites, so this pruning has no completeness guarantee.
  The default0 preserves the prior archive behavior. Campaign arms
  anchor8_qasm2 and anchor8_resource_qasm2 isolate this change against their
  corresponding anchor8 baselines, with paired frozen/online policies.
  Full-state checkpoints retain group signatures/counters, and replay audits
  reconstruct every admission, eviction and restart from verified QASM hashes.

  Diagnostic evidence: prior-path-diagnostics.json covers47 closed reports in
  the original prior/LR study, which failed overall because3 other trials
  raised vendor-wrapped deadline alarms. Of438618 recorded transitions,
  189847 were more than6 gates above the incumbent.52 of89 strict improvement
  events had a current restart-trajectory prefix crossing that threshold.
  These are observational counts (some frozen LR controls duplicate paths),
  not independent samples or a prediction of counterfactual truncated search.
  Prefixes do not include ancestry before their buffer restart. This evidence
  does not justify enabling a global incumbent+6 bound without an ablation.
  The64-state scored pools had median known extracted-QASM counts4.5 frozen
  and2 online (63mapped states), with most raw states close to the node cap.
  Different normalized graph keys remain common; exact view dedup alone would
  not remove most of these completion-equivalent raw variants.
